================================================================================

Act as a Senior C# .NET Developer. I am building a Localhost Library Management
System using ASP.NET Core MVC (.NET 8) with Entity Framework Core and SQL Server
LocalDB.

Generate a clean, production-ready MVC application architecture covering the
following specific requirements:

### 1. Data Models & Entity Framework
Define the C# class models using Entity Framework Core annotations and relationships:
- UserType (Id, TypeName [e.g., Student, Faculty], MaxBorrowLimit, FineRatePerDay)
- ApplicationUser (Extends IdentityUser with UserTypeId, FullName)
- Book (Id, Title, Author, ISBN, Genre, TotalCopies, AvailableCopies)
- BorrowRecord (Id, UserId, BookId, BorrowDate, DueDate, ReturnDate, FineAmount, IsReturned)
- Invoice (Id, BorrowRecordId, UserId, TotalFine, IssuedDate, IsPaid)

### 2. Core Business Logic Services
Implement a `IBorrowService` and `BorrowService` containing methods for:
a. BorrowBookAsync(userId, bookId): Check if user reached their UserType.MaxBorrowLimit
   and if Book.AvailableCopies > 0. If valid, decrement AvailableCopies and create
   BorrowRecord.
b. ReturnBookAsync(borrowRecordId): Calculate fine based on Overdue Days *
   UserType.FineRatePerDay. Create an Invoice record if fine > 0. Increment AvailableCopies.
c. GetMostBorrowedBooksAsync(int topCount): Query top N books ordered by borrow frequency.
d. GetRecommendationsForUserAsync(string userId): Simple recommendation logic based on
   genres the user frequently borrows.

### 3. Controllers & PDF Reporting
- Implement a `ReportsController` that uses the 'QuestPDF' library to generate and download:
  1. A downloadable PDF Fine Invoice for a given BorrowRecord/Invoice ID.
  2. A downloadable PDF Monthly Borrowing Summary Report.

### 4. UI/Views (Razor Views + Bootstrap)
- Create a clean Admin Dashboard displaying:
  - Total Books, Active Borrows, Overdue Fines.
  - A table of "Most Borrowed Books".
  - Quick action buttons to issue/return books and download PDF reports.

Please provide modular, dependency-injected C# code with clear comments,
asynchronous DbContext calls, and proper error handling.
